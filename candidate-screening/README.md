Candidate Screening

Overview

This project demonstrates a structured approach to reviewing candidates against the requirements of a job.

Screening Criteria

Candidates are reviewed based on:

* Relevant experience
* Required skills
* Education and certifications
* Communication skills
* Technical skills
* Availability
* Work authorization where applicable

Screening Process

1. Review the job description.
2. Identify required qualifications.
3. Review the candidate’s CV.
4. Compare experience and skills with the requirements.
5. Record relevant evidence.
6. Move suitable candidates to the next stage.

Screening Outcome

Candidates can be categorized as:

* Strong Match
* Potential Match
* Not a Match

Screening decisions should be based on job-related evidence and consistent criteria.

Outcome

This project demonstrates my ability to support structured and consistent candidate screening.
