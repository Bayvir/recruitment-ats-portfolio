Job Description Analysis

Example Role

Customer Support Representative

Key Requirements

* Strong written and verbal communication
* Customer service skills
* Problem-solving ability
* Basic computer skills
* Ability to work independently
* Ability to use online tools and communication platforms

Preferred Skills

* Previous customer support experience
* CRM or ATS experience
* Microsoft Office or Google Workspace
* Data entry experience

Recruitment Screening Criteria

When reviewing candidates, I would compare their CVs against the requirements of the role.

Must-Have Criteria

* Communication skills
* Customer service ability
* Basic computer proficiency
* Relevant work experience where required

Nice-to-Have Criteria

* CRM experience
* ATS experience
* Data entry experience
* Experience working remotely

Candidate Matching

Candidates can be categorized as:

* Strong Match
* Potential Match
* Not a Match

The assessment should be based on evidence from the candidate’s application and should be applied consistently across candidates.

Outcome

This project demonstrates my ability to analyze job descriptions, identify recruitment criteria, and use those criteria to support candidate screening.
